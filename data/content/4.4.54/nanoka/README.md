# Generated Nanoka Canonical Content

This ignored directory contains deterministic Canonical JSONL records derived
only from `data/external/nanoka/4.4.54`.  Delete it freely and rebuild it with:

```powershell
python scripts/build_content_db.py 4.4.54
```

The files are an auditable intermediate form; SQLite is a query layer, never
the only source of content truth.
