# HSR Battle Agent

一个面向《崩坏：星穹铁道》战斗研究的长期项目骨架。最终目标是：

1. 获取并版本化保存游戏战斗配置与运行时数据；
2. 构建可验证、可跨版本更新的战斗沙箱；
3. 从真实客户端读取当前战斗状态；
4. 使用搜索器与模型生成实时战斗策略；
5. 通过研究前端和实时顾问前端展示数据、差异与建议。

## 当前状态

当前默认状态是：**零业务代码、零原始游戏数据、零稳定接口**。

因此本仓库只预留稳定职责边界，不提前假定具体解包格式、客户端读取方法、BattleState 字段或模型结构。各任务按 `docs/roadmap.md` 基本线性推进，模块在真正需要联动时再建立接口。

## 目录原则

- `tools/`：外部数据获取、解包、运行时采集和迁移工具。
- `src/hsr_battle_agent/`：经过验证后沉淀的正式业务代码。
- `apps/`：研究前端和最终实时顾问前端。
- `data/`：按版本保存的不可变数据产物，不提交大型原始文件。
- `schemas/`：稳定后才接受的数据结构版本和迁移。
- `registry/`：记录当前版本、兼容关系和模型别名。
- `docs/tasks/`：独立任务说明；任务顺序不进入代码目录名。
