# T00 项目骨架与版本规则

## 目标

在没有业务代码和数据时建立不会因后续功能增加而推翻的目录、版本和产物规则。

## 子任务

- 建立根目录和 Python 包骨架；
- 定义 `data/` 分层；
- 定义 Manifest 最小字段；
- 定义游戏版本、快照、沙箱 Release、数据集和模型命名；
- 建立 Registry 示例；
- 建立跨版本测试目录。

## 输出

`README.md`、`docs/versioning.md`、`schemas/manifests/`、`registry/`。

## 验收

加入新游戏版本、新读取器、新模型时不需要改变顶层职责目录。
